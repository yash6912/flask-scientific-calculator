# 🧮 Flask Scientific Calculator

A modern and responsive scientific calculator web application built using
Python, Flask, HTML, CSS, and JavaScript.

The application supports basic arithmetic operations as well as advanced
scientific calculations, calculation history, keyboard input, and
DEG/RAD modes.

## ✨ Features

- Basic arithmetic operations
- Addition, subtraction, multiplication and division
- Scientific calculations
- Trigonometric functions
- Inverse trigonometric functions
- DEG/RAD mode
- Square root
- Powers and exponents
- Factorial
- Percentage calculations
- Logarithm and natural logarithm
- Pi (π) and Euler's number (e)
- Calculation history
- Clear history functionality
- Keyboard support
- Responsive user interface
- Flask backend for calculation processing

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Jinja2**
