🧮 Flask Scientific Calculator

A modern and responsive scientific calculator web application built
using Python, Flask, HTML, CSS, and JavaScript.

The application provides a clean calculator interface with basic
arithmetic, scientific functions, calculation history, and a responsive
user experience.

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/yash6912/flask-scientific-calculator.git

2. Open the project

cd flask-scientific-calculator

3. Create a virtual environment

Windows:

python -m venv flaskenv

4. Activate the virtual environment

Windows PowerShell:

flaskenv\Scripts\Activate.ps1

Windows Command Prompt:

flaskenv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Run the Flask application

python app.py

7. Open the application

Open your browser and visit:

http://127.0.0.1:5000
